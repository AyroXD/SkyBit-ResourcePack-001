# SkyBit Resource Pack

Official custom resource pack for **SkyBit Network**.

## Current version

**v3.4.0** — Minecraft Java **1.21.11** / resource-pack format **75**.

Includes upgraded SkyBit UI, custom crate visuals, Mythic crate/key, custom gear, armor icons and 3D-style weapon/tool models used by SkyBitCore 3.4.0.

```text

```

## Build

The pack is generated by `tools/generate_pack.py` and GitHub Actions validates and commits the generated ZIP + SHA1.

Older generated pack files were removed so `main` only exposes the current v3.4.0 release.
