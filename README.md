# SkyBit Ultimate Resource Pack

Official custom resource pack for **SkyBit Network**.

## Current development release

**v5.0.0** — Minecraft Java **26.2** — Resource Pack **88.0**.

The v5 line implements the complete 92-item SkyBit Ultimate specification as a coherent Fantasy + Medieval + Arcane visual system instead of a collection of unrelated recolors.

### v5 status

- **92/92 canonical custom item IDs generated**
- modern `assets/skybit/items/...` item definitions using namespaced `minecraft:item_model`
- separate readable inventory icons and custom world/hand models where appropriate
- **35 custom 3D item models**
- **20 animated high-value items** with subtle loops
- Basic / Rare / Epic / Legendary / Mythic / Vote visual language
- VIP, Knight, Baron, King and Emperor badge progression
- six key, fragment and crate families plus mine crystals
- SkyCoin economy assets, contracts, AFK, enchants, guild, bounty, treasure and event assets
- relics, professions, renown, GUI icons, boosters, vouchers and cosmetics
- Skyfang Blade, Ember Cleaver, Stormcaller Spear, Void Reaver, Frostbite Bow and Titan Pickaxe
- Stormguard, Emberforged and Voidwarden equipment assets / 12 armor items
- rarity tooltip sprites
- EN / SK / CZ / DE / HU translation files
- central JSON item registry and plugin integration YAML
- development test commands, asset checklist, style/model guides and validation report
- structural validation: **PASS**
- live visual QA in Minecraft 26.2: **NEEDS IN-GAME TESTING**

## Build

`.github/workflows/build-resource-pack-v5.yml` reconstructs the production generator, installs Pillow + PyYAML, generates the complete pack, runs structural validation, verifies the final ZIP independently and publishes the generated v5 assets back to `main`.

The build checks the exact Resource Pack 88.0 compatibility range, all **92** modern item definition files, key showcase assets and the final SHA-1 before publishing.

## Live server compatibility

The current SkyBit server repository still targets **Paper 1.21.11**, so its `server.properties` intentionally remains on the v4 / 1.21.11 pack. Do not switch the live server to v5 until the backend is upgraded to Minecraft 26.2 and the v5 pack passes in-game QA.

Older v3.7 and v4 files remain available as rollback builds during migration.
