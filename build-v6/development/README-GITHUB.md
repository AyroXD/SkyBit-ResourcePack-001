# SkyBit Resource Pack v6.0.0

Target: **Minecraft Java 1.21.11** (resource-pack format 75).

This build intentionally uses **2D models for every custom item except crates**. Basic, Rare, Epic, Legendary, Mythic and Vote crates keep dedicated 3D models. This removes the oversized/broken 3D item presentation seen in-game while preserving custom crate displays.
